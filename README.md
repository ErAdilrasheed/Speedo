Speedo – Taxi Booking App 🚖
Speedo is a full-featured taxi booking application built using Java Spring Boot. The project simulates the core backend functionality of a ride-hailing platform, including user registration, driver management, ride booking, and trip status updates.

🚀 Features
User Registration & Login (Passenger & Driver)

Book a Ride based on available drivers and location

Driver Dashboard to accept or reject ride requests

Trip Management (Start, End, Cancel rides)

Admin Controls for monitoring users and rides

RESTful APIs built with Spring Boot and tested using Postman

🛠️ Tech Stack
Backend: Java, Spring Boot, Spring MVC, Spring Data JPA

Database: MySQL / H2 (for testing)

Tools: Git, GitHub, Postman, Maven

📁 Project Structure
controller – handles all incoming API requests

service – contains business logic

repository – manages data access

model – defines all entities

dto – handles data transfer objects

💡 Learning Outcome
This project helped strengthen my skills in:

Building REST APIs with Spring Boot

Entity relationships and database design

Handling real-world backend logic like ride assignment and trip flow

Writing clean, modular, and testable code
